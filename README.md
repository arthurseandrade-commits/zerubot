## 📋 Sobre

**ZeruBot** é um bot Discord alimentado por Inteligência Artificial, projetado para fornecer respostas inteligentes e ajudar servidores com suporte automatizado. Completamente gratuito e fácil de usar!

### ✨ Por que usar o ZeruBot?

- 🧠 **IA Avançada** - Respostas contextuais e inteligentes
- ⚡ **Rápido** - Respostas em segundos
- 🆓 **Gratuito** - Sem custos ocultos ou planos premium
- 🔧 **Fácil** - Setup em menos de 1 minuto
- 🔒 **Seguro** - Código limpo e confiável
- 🌐 **24/7** - Disponível sempre que você precisar

## 📚 Comandos

| Comando | Descrição | Exemplo |
|---------|-----------|---------|
| `/ask` | Faça uma pergunta ao bot e receba uma resposta da IA | `/ask Como funciona a fotossíntese?` |
| `/help` | Exibe o menu de ajuda com todos os comandos | `/help` |

### 💡 Exemplos de Uso

```
/ask Qual é a capital da França?
→ A capital da França é Paris.

/ask Me explique o que é programação
→ Programação é o processo de criar instruções...

/ask Como posso melhorar meu servidor Discord?
→ Aqui estão algumas dicas para melhorar seu servidor...
```

## 🚀 Instalação

### Método 1: Convite Direto (Recomendado)
1. Clique no [link de convite](https://discord.com/oauth2/authorize?client_id=1467941142220767423&permissions=8&integration_type=0&scope=bot+applications.commands)
2. Selecione seu servidor
3. Autorize as permissões
4. Pronto! Use `/help` para começar

### Método 2: Self-Hosting (Avançado)

Se você deseja hospedar sua própria instância do bot:

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/zerubot.git
cd zerubot

# Instale as dependências
npm install
# ou
pip install -r requirements.txt

# Configure as variáveis de ambiente
cp .env.example .env
# Edite o arquivo .env com seu token

# Inicie o bot
npm start
# ou
python bot.py
```

#### Variáveis de Ambiente

```env
DISCORD_TOKEN=seu_token_aqui
AI_API_KEY=sua_chave_api_aqui
PREFIX=/
```
